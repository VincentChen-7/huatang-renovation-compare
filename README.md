## 两套方案

- **方案 A**：局改施工造价书（¥150,206.75）＋ 拉迷全屋定制柜（¥248,888）≈ **¥38.5–40 万**
- **方案 B**：全案套餐 —— 设计＋施工（¥115,200–144,720）＋ 克诺斯邦F4★定制（¥170,000–176,550）＋ 拆除 ≈ **¥29.5–33.1 万**

## 核心结论

1. **同口径下 A 比 B 贵约 7–10 万**，但 A 柜子板材（生态澳松板、五金未标明）档次低于 B（进口克诺斯邦 F4★＋百隆＋松下）。
2. **A 强在湿区硬改**：主卫＋两处公卫整体拆除重建、阳台重做防水、砌墙改格局；但厨房无施工、水电为局部改造、网线/智能留白。
3. **B 强在覆盖完整**：逐房间列工艺、水电全套＋松下开关房门窗帘门套全包、定制环保顶配且更便宜；卫生间仅修补翻新、不动格局。
4. 比价前必须：①两家对齐定制投影面积/五金/环保等级；②确认卫生间动不动格局；③A 补厨房与储藏室柜体报价。
